# Legacy Web parity inventory

This inventory treats the root browser application as the composition of `index.html`, `js/app.js`, `js/bootstrap/`, `js/ui/`, and the shared engine beneath `js/core/`, `js/data/`, `js/domain/`, `js/platform/`, and `js/i18n/`. A screen module is not automatically a route: the authoritative route registry is `Router.routes` in `js/ui/navigation/router.js`.

Discovered baseline: **59** JavaScript modules under `js/ui/screens/` and **26** registered routes. Route parameters are state objects persisted in browser history, not URL path segments.

## Non-route presentation modules that remain parity-critical

- Home layout renderers and focus/load policies are states of `home`, not separate routes.
- Detail hero/episode modules, player overlays/subtitle dialogs, stream virtualization/empty state, and settings sub-sections are nested states of their parent route.
- `sidebarNavigation`, `webNavigation`, `webPlayerControls`, focus engine, route state restoration, overlays and browser history are application-shell behavior and must be represented even though they are not routes.
- The legacy source tree remains only where shared compatibility imports and regression tests still reference it. The root build no longer bundles or serves `js/app.js`, `js/bootstrap/`, legacy screen renderers, or legacy CSS; `apps/web` is now the sole production presentation.

## Verification notes

- The route table has no unresolved user-facing entries. `plugin` and add-on remote mode intentionally converge on the new Sources presentation; `debugConsole` remains explicitly internal.
- Collection folders resolve addon, TMDB and Trakt sources through a DOM-free shared loader, expose source tabs and pagination, and retain profile-scoped store ownership.
- Library includes saved/list views, removal, profile-scoped collections, and Debrid cloud file resolution into the shared Player pipeline.
- Player presentation and controller integration are implemented. Brave exercised native WebM, public HLS and public MPEG-DASH sources through the shared `PlayerController`, including rendered video, duration/progress, track discovery and terminal behavior. HLS selected `hls.js`; DASH selected `dash.js` after fixing engine selection to occur after its adaptive library is available. Platform AVPlay remains `BLOCKED BY ENVIRONMENT` because Brave cannot emulate Tizen playback hardware.
