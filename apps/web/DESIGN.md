# Design System: Nuvio Web

**Stitch Project ID:** 5092809079354259052

## 1. Visual Theme & Atmosphere

An artwork-dominant, theatrical streaming interface on a deep near-black canvas. Frosted navigation and controls preserve the sense of depth without turning the experience into a dashboard. Interaction is precise and quiet: cobalt light is reserved for actionable focus, playback progress and primary decisions.

## 2. Color Palette & Roles

- **Obsidian Canvas (#090B10):** the lowest page and immersive-player layer.
- **Deep Slate Card (#11141D):** cards, inputs and modal chassis.
- **Lifted Slate (#191E2B):** hover and elevated container state.
- **Electric Cobalt (#3B82F6):** primary CTAs, focus boundaries and progress.
- **Sky Glow (#60A5FA):** hover illumination and high-priority emphasis.
- **Deep Cobalt (#1D4ED8):** pressed states and restrained ambient gradients.
- **High White (#F8FAFC):** titles and primary labels.
- **Muted Slate (#94A3B8):** synopsis and secondary metadata.
- **Subdued Slate (#64748B):** tertiary timestamps and credits.
- **Hairline White (rgba(255,255,255,0.08)):** surface separation.

## 3. Typography Rules

Space Grotesk provides geometric, widescreen display and headline roles. Manrope provides readable body, label and control text. Desktop hero titles reach 56px/64px at bold weight; mobile display contracts to 36px/44px. Metadata badges use 11px bold Manrope with generous uppercase tracking.

## 4. Component Stylings

- **Buttons:** Primary actions are cobalt pill controls; secondary actions use restrained frosted glass with a thin light rim. Icon controls are 44px circular glass disks.
- **Cards/Containers:** Posters use 2:3 artwork and episodes/continue-watching use 16:9 artwork. Default corners are subtly rounded at 8px; expanded containers use 16px. Focus scales cards to roughly 1.04 with a visible cobalt boundary and soft cobalt glow.
- **Inputs/Forms:** Deep slate interiors, high-contrast labels and an unmistakable cobalt focus ring. Inputs must remain fully keyboard and remote operable.
- **Navigation:** A 64px desktop frosted header becomes purpose-built bottom navigation on mobile.
- **Player:** Controls float above native video with a low-contrast timeline, buffered indication and cobalt played progress.

## 5. Layout Principles

Desktop uses fluid widescreen heroes and horizontal rails with 3.5rem outer margins. Tablet contracts to 2rem and mobile to 1rem. Rail gaps are 1rem, section labels sit 0.5rem above content, and major groups use 1.5–2.5rem rhythm. Backdrops dissolve into the canvas through directional and radial vignette gradients; controls never compete with artwork.
